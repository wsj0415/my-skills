## Final QA

### Story
- [ ] Title-only test passes
- [ ] Executive summary states the answer, not the agenda
- [ ] Every slide has one primary job
- [ ] Main deck excludes nonessential appendix detail

### Evidence
- [ ] Every material claim has evidence
- [ ] Units, periods, denominators and calculations are verified
- [ ] Sources are traceable
- [ ] Claims do not exceed the evidence

### Design
- [ ] Main point is apparent in ~3 seconds
- [ ] Action title and key evidence survive zoomed-out / 3-metre inspection
- [ ] Layout, color semantics and typography are consistent
- [ ] No decorative element competes with evidence

### Engineering
- [ ] All slides rendered and visually inspected
- [ ] No unintended overflow
- [ ] No unintended overlap
- [ ] Fonts verified
- [ ] Editable objects preserved where practical
