# Content Evaluator - 内容评估技能

## 技能用途

对任意文本内容进行**六维度质量评分**，输出结构化分析报告，包含分数、评语、改进建议和爆款预测。

## 评分维度（6 Core Dimensions）

| 维度 | 英文名 | 分值范围 | 核心评估要点 |
|------|--------|----------|--------------|
| **Hook 钩子** | Hook Strength | 0-100 | 标题吸引力、开头是否引发点击欲望、悬念设置 |
| **互动速度** | Velocity | 0-100 | 内容引发互动（评论/点赞/收藏）的潜力 |
| **话题新颖度** | Novelty | 0-100 | 选题差异化、时效性、稀缺性 |
| **受众匹配度** | Audience Fit | 0-100 | 目标受众定位准确度、需求命中程度 |
| **实用价值** | Practical Value | 0-100 | 信息价值、可操作性、知识密度 |
| **传播诱因** | Shareability | 0-100 | 情感共鸣、争议性、转发动机强弱 |

## 评分标准参考

### Hook 钩子 (0-100)
- **90-100**: 标题极具吸引力，悬念或利益点明确，点击欲望强烈
- **70-89**: 标题有吸引力，能引发好奇或共鸣
- **50-69**: 标题平淡，缺少亮点但尚可接受
- **30-49**: 标题缺乏吸引力或过于平淡
- **0-29**: 标题毫无吸引力，甚至让人不想点击

### Velocity 互动速度 (0-100)
- **90-100**: 内容极具讨论性，引发深度互动和讨论
- **70-89**: 内容能引发点赞、收藏、简单评论
- **50-69**: 内容尚可，但互动诱因一般
- **30-49**: 内容较难引发互动
- **0-29**: 内容枯燥，无互动点

### Novelty 话题新颖度 (0-100)
- **90-100**: 全新角度、前沿话题、无类似内容
- **70-89**: 有一定新意，角度略有不同
- **50-69**: 话题常见但内容处理有特色
- **30-49**: 话题老旧，同质化严重
- **0-29**: 完全重复热点，无任何新意

### Audience Fit 受众匹配度 (0-100)
- **90-100**: 精准命中目标群体痛点，需求强烈
- **70-89**: 基本命中目标群体，有一定吸引力
- **50-69**: 受众定位模糊，覆盖面过广或过窄
- **30-49**: 受众定位错误，内容与受众不匹配
- **0-29**: 完全偏离目标受众

### Practical Value 实用价值 (0-100)
- **90-100**: 提供稀缺知识、可直接操作的干货
- **70-89**: 有实用价值，信息量大
- **50-69**: 有一定价值但深度不足
- **30-49**: 价值较低，多为泛泛而谈
- **0-29**: 无实际价值，纯粹情绪输出

### Shareability 传播诱因 (0-100)
- **90-100**: 强情感共鸣或强争议性，转发动机极强
- **70-89**: 有分享价值，读者愿意转发
- **50-69**: 分享价值一般
- **30-49**: 缺乏分享动机
- **0-29**: 完全没有分享价值

## 综合评分计算

```
综合评分 = Hook×25% + Velocity×15% + Novelty×15% + Audience×20% + Value×15% + Share×10%
```

## 爆款等级划分

| 综合评分 | 等级 | 爆款概率 | 说明 |
|----------|------|----------|------|
| 85-100 | S级 | 50-70% | 极有可能成为爆款 |
| 70-84 | A级 | 30-50% | 有爆款潜力 |
| 55-69 | B级 | 15-25% | 中上水平 |
| 40-54 | C级 | 5-10% | 一般水平 |
| 0-39 | D级 | <5% | 较差 |

| Velocity 互动速度 | XX/100 | [具体评语] |
| Novelty 话题新颖度 | XX/100 | [具体评语] |

### HTML 格式

使用 `assets/report-template.html` 模板，替换相应变量后输出自包含的 HTML 文件。

## 工作流程

1. **接收内容**: 获取用户提供的文本内容
2. **六维评分**: 对每个维度进行 0-100 打分
3. **计算综合**: 按权重计算加权总分
4. **生成评语**: 为每个维度撰写 50-100 字的具体评语
5. **输出报告**: 根据用户要求输出 Markdown 或 HTML 格式

## 注意事项

- 评分基于内容本身质量，不受字数多少影响
- 评语需具体、有建设性，避免空泛评价
- 中文内容优先使用中文评语，英文内容使用英文评语
- HTML 报告需单文件自包含（内嵌所有样式）
